# d3jusdevspace — Style Guide
**Version:** 1.0 | **Last updated:** April 2026

This is the canonical design token reference for d3jusdevspace. All UI work — whether written by a human developer, generated by an AI agent, or built in a design tool — must reference these tokens. Do not use hardcoded colour values anywhere in the codebase; always reference the CSS custom properties defined here.

---

## 1. Colour Palette

### Design philosophy
The palette is adapted from the author's portfolio site. It retains the core brand identity (deep navy dark mode, cyan/blue accent, technical aesthetic) while being tuned for long-form reading comfort. The key adjustments from the original portfolio palette are:
- Body text softened from pure white to `#e8eaf0` to reduce eye fatigue on dark backgrounds
- Dark surface colours spread further apart to create visible layout hierarchy
- Light mode backgrounds shifted from warm pinkish-grey to a cooler neutral
- Neon glow effects reserved for specific accent moments only (site name, Agent badge, active nav) — not general UI

### Colour usage rules

| Token | Use it for | Never use it for |
|-------|-----------|-----------------|
| `--color-bg-page` | Page background only | Component backgrounds |
| `--color-bg-surface` | Cards, admin panels, sidebar, nav | Page background |
| `--color-bg-elevated` | Dropdowns, modals, tooltips, hover | Default component bg |
| `--color-bg-subtle` | Code blocks, tag pills, blockquotes | Large surfaces |
| `--color-accent` | Links, active states, CTAs, the Agent badge | Body text, large backgrounds |
| `--color-accent-muted` | Tag pill backgrounds, icon backgrounds | Text |
| `--shadow-neon-accent` | Site logo, Agent badge, active nav item only | Every interactive element |

## 2. Typography

### Font stack

```css
@import url("https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@300..700&display=swap");
@import url("https://fonts.googleapis.com/css2?family=JetBrains+Mono:ital,wght@0,100..800;1,100..800&display=swap");
@import url("https://fonts.googleapis.com/css2?family=Montserrat:ital,wght@0,100..900;1,100..900&display=swap");

@layer base {
  :root {
    --font-body:    "Space Grotesk", sans-serif;    /* all prose, UI text */
    --font-mono:    "JetBrains Mono", monospace;    /* code blocks, metadata, labels, site name */
    --font-display: "Montserrat", sans-serif;       /* hero headings, large display text only */
  }
}
```

### Font assignment rationale

| Font | Role | Why |
|------|------|-----|
| Space Grotesk | Body, UI | Geometric sans — highly readable at 14–18px for long-form reading, modern feel that fits the technical aesthetic |
| JetBrains Mono | Code, metadata, nav labels, site name, badges | Retains the "developer" identity from the portfolio without inflicting monospace on paragraph text |
| Montserrat | Post titles on the detail page, section hero headings | Weight contrast and elegance at large sizes; not used below 24px |

### Type scale

```css
:root {
  /* Display */
  --text-display:    2.5rem;    /* 40px — post hero title on detail page */
  --text-h1:         2rem;      /* 32px — page-level headings in admin */
  --text-h2:         1.5rem;    /* 24px — section headings */
  --text-h3:         1.25rem;   /* 20px — sub-section headings */
  --text-h4:         1.125rem;  /* 18px — card titles, sidebar headings */

  /* Body */
  --text-body-lg:    1.125rem;  /* 18px — post body copy (detail page) */
  --text-body:       1rem;      /* 16px — UI text, admin forms */
  --text-body-sm:    0.9375rem; /* 15px — secondary UI text */

  /* Small */
  --text-caption:    0.875rem;  /* 14px — metadata, timestamps, labels */
  --text-xs:         0.75rem;   /* 12px — tags, badges, helper text */

  /* Line heights */
  --leading-tight:   1.25;      /* headings */
  --leading-snug:    1.4;       /* sub-headings, UI text */
  --leading-normal:  1.6;       /* general body */
  --leading-relaxed: 1.8;       /* post body copy — most readable for long-form */

  /* Font weights */
  --weight-regular:  400;
  --weight-medium:   500;
  --weight-semibold: 600;
  --weight-bold:     700;
}
```

### Typography usage rules

- Post body copy: `Space Grotesk`, `var(--text-body-lg)`, `var(--leading-relaxed)`
- Code blocks: `JetBrains Mono`, `var(--text-caption)` — background `var(--color-bg-subtle)`
- Inline code: `JetBrains Mono`, `var(--text-caption)`, background `var(--color-bg-subtle)`, padding `2px 6px`, border-radius `4px`
- Site name / logo: `JetBrains Mono`, bold — with `var(--shadow-neon-accent)` applied
- Post titles on detail page: `Montserrat`, `var(--text-display)`, `var(--weight-bold)`
- Post card titles on feed: `Space Grotesk`, `var(--text-h4)`, `var(--weight-semibold)`
- Metadata (date, read time, author): `JetBrains Mono`, `var(--text-xs)`, `var(--color-text-secondary)`
- Never use Montserrat below 20px — it loses its character at small sizes

## 8. Iconography

Use **Lucide React** throughout. Icon size defaults:

```css
--icon-sm:  16px;   /* inline icons, badge icons */
--icon-md:  20px;   /* button icons, nav icons */
--icon-lg:  24px;   /* feature icons, empty state icons */
```

Icon colour should always inherit from `color` — never hardcode a fill. Use `currentColor` in SVG paths.

## 10. Animation

```css
:root {
  --transition-fast:   100ms ease;
  --transition-base:   150ms ease;
  --transition-slow:   250ms ease;
  --transition-layout: 300ms ease;
}

/* Reading progress bar */
@keyframes progress-fill {
  from { width: 0%; }
}

/* Skeleton loading pulse */
@keyframes skeleton-pulse {
  0%, 100% { opacity: 0.4; }
  50%       { opacity: 0.8; }
}
```

All animations must respect `prefers-reduced-motion`:

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration:   0.01ms !important;
    transition-duration:  0.01ms !important;
  }
}
```
